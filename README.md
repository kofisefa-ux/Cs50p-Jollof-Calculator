# 🍛 Jollof Party Cost & Ingredient Calculator

A clean, interactive command-line Python program designed to take the guesswork out of event planning. Built as a practical application of foundational concepts from **Harvard's CS50P (Introduction to Programming with Python)**.

## 🚀 About the Project
Hosting a gathering requires precise planning—especially when cooking a massive pot of Jollof rice! This tool allows a host to enter the number of attending guests, automatically calculates the exact raw ingredients needed based on fixed culinary ratios, translates those quantities into actual store-bought packages, and breaks down itemized and total estimated budgets.

## 💡 Key Features
* **Dynamic Scaling:** Automatically multiplies ingredient ratios (rice, tomato puree, onions, meat) based on user input.
* **Smart Market Packaging:** Converts raw recipe requirements into realistic retail quantities (e.g., 5-cup rice bags, 0.5L puree cans, and 1kg meat packs).
* **Automated Budgeting:** Computes itemized costs and calculates a grand total estimated budget using clean floating-point math and formatted currency strings.
* **User-Friendly Output:** Utilizes Python f-strings for clear, readable terminal summaries.

## 🛠️ Tech Stack & Concepts
* **Language:** Python 3
* **Concepts Practiced:** 
  * Functions (`def main()`)
  * User input & typecasting (`input()`, `int()`, `float()`)
  * Mathematical operators & variable binding
  * Formatted string literals (`f-strings` with decimal precision control like `:.2f`)
